frequently asked questions

How do I add audiobooks to the app?

Tap the "+" button in your library to import M4B files from your device or iCloud Drive. If you have Audiobookshelf configured, you can also browse and download from your server.

Which file formats are supported?

Listen This supports M4B and M4A audiobook files. These formats preserve chapter information and are widely used by audiobook providers.

How does iCloud sync work?

Your audiobook library and playback progress sync automatically via iCloud. Start listening on your iPhone and continue on your iPad or Apple Watch. Make sure iCloud is enabled for Listen This in your device settings.

How do I listen on Apple Watch?

Open the Watch app, select an audiobook, and tap the download button. Once downloaded, you can listen offline during workouts or walks without your iPhone nearby.

How can I transfer audiobooks to Apple Watch faster?

For the fastest transfer, swipe left on an audiobook in your iPhone library and tap "Transfer". Once uploaded to iCloud, open the Watch app and download the audiobook - it will transfer via iCloud instead of Bluetooth, which is much faster for large files.

How do I connect to Audiobookshelf?

Go to Settings and configure your server:

  1. Server URL - Enter your server address, either local (e.g., http://192.168.1.123:13378) or remote (e.g., https://audiobooks.example.com)
  2. API Key - Generate a key in Audiobookshelf: Settings → Users → [Your User] → API Tokens → Create
  3. Test Connection - Tap to verify your settings work
  4. Enable - After a successful test, toggle on "Enable Audiobookshelf"

Troubleshooting: Make sure your phone is on the same network as your server. If using a domain, check that DNS resolves correctly. Double-check the API key has no extra spaces.

How does the sleep timer work?

Tap the moon icon in the player to set a sleep timer. When the timer is about to end, shake your device to extend it if you're not ready to stop listening.

How do I delete an audiobook or view details?

Swipe right on an audiobook in your library to reveal Info and Delete buttons.

My audiobook isn't importing correctly

Make sure the file is a valid M4B or M4A file. If importing from iCloud, ensure the file is fully downloaded. For very large files, the import may take a moment.
